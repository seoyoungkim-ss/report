# 썸머탈출 페스티벌 — 실시간 스코어보드

사내 게임데이 "썸머탈출 페스티벌" 행사용 실시간 스코어보드.

- `index.html` — React 단일 파일 앱. 75인치 TV/플립 **송출 화면**과 진행자용 **관리자 모드**를 함께 담고 있음.
- **완전 오프라인 동작**: React/ReactDOM까지 파일 안에 전부 내장(CDN·외부 서버·인터넷 요청 없음). 사내망에서 claude.ai를 포함한 외부 인터넷 접속이 막혀 있어도 그대로 동작함.
- 노트북 한 대에서 HDMI로 TV에 화면을 직접 미러링/확장하는 구성을 전제로 함 — 별도 서버나 다른 기기와의 네트워크 통신이 필요 없음.
- 관리자 모드 진입: URL에 `?admin=1` 추가, 또는 화면 우측 하단의 눈에 잘 안 띄는 작은 점(•) 버튼 클릭.

## 사용 방법 (행사 당일)

1. `index.html`을 노트북에서 Chrome 등 브라우저로 더블클릭해서 엽니다 (인터넷 연결 불필요).
2. 노트북을 HDMI로 TV/플립에 연결합니다.
3. 평소에는 **송출 화면**(기본 모드)을 그대로 띄워둡니다. 전체화면은 브라우저 `F11`.
4. 결과를 입력할 때만 화면 우측 하단의 작은 점(•)을 클릭해 **관리자 모드**로 전환 → 입력 후 다시 클릭해 송출 화면으로 복귀합니다. (관리자 모드 화면도 그대로 TV에 보이니, 입력은 빠르게 하고 바로 전환하는 걸 권장.)
5. 입력한 내용은 이 브라우저의 `localStorage`에 자동 저장되어 새로고침해도 유지됩니다. **단, 이 노트북·이 브라우저에서만 유지**되므로 다른 기기/브라우저에서는 보이지 않습니다.

## 데이터 모델

- `teams`: 9개 팀(플랫폼) — 이름, 컬러, 팀장 이미지(파일 업로드 시 압축 후 base64로 저장)
- `days.day1~day4`: 일자별 대진표(토너먼트, 부전승 자동 처리) 또는 순위(완료 시간 기준 자동 정렬 / 수동 순서 지정)
  - Day1: 매치별 "선공/후공 판정" 스톱워치(10초 목표) 포함
  - Day2: 매치별 세트 스코어(예: 2:1) 입력 필드 포함
- `scoring`: Day별 라운드 통과 점수 / 순위별 점수, 임원 참여 가중치(배수), 임원 참여 팀 목록
- `display.activeDayKey`: 송출 화면에 표시할 오늘의 Day (관리자가 "화면 제어" 탭에서 선택)

## 참고: 이전 Claude Artifact 버전

Claude Artifact(claude.ai)의 실시간 DB 기능으로 관리자 입력 → 다른 기기(TV)에 자동 동기화되는 버전도 만들어봤으나, 사내망에서 claude.ai 접속 자체가 막혀 있어 이번 행사에는 쓸 수 없음. 그래서 위와 같이 노트북 한 대·완전 오프라인 구성으로 다시 만들었음.

## 빌드 방법 (소스 수정 시)

`index.html`은 사람이 직접 짠 JSX를 Babel로 미리 컴파일하고 React/ReactDOM UMD 번들을 파일 안에 합쳐 넣은 결과물이라, 수정할 때는 원본 JSX를 고치고 다시 빌드해야 함(직접 `index.html`의 압축된 React 코드를 건드리면 안 됨). 원본 JSX와 빌드 스크립트는 별도로 요청하면 추가 제공 가능.
