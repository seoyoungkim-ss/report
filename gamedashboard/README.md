# 썸머탈출 페스티벌 — 실시간 스코어보드

사내 게임데이 "썸머탈출 페스티벌" 행사용 실시간 스코어보드.

- `index.html` — React 단일 파일 앱. 75인치 TV/플립 **송출 화면**과 진행자용 **관리자 모드**를 함께 담고 있음.
- Claude Artifact의 `db` 캡슐화 기능(조직 내부 실시간 공유 문서 저장소)을 사용해, 관리자가 입력하면 송출 화면에 즉시(실시간 구독) 반영됨.
- 관리자 모드 진입: URL에 `?admin=1` 추가, 또는 화면 우측 하단의 숨겨진 작은 버튼 클릭.

## 게시된 Artifact

https://claude.ai/code/artifact/ed7149bd-8912-46b1-8d37-56f9c308e549

이 링크는 조직 내부 로그인 사용자만 접근 가능(실시간 DB 특성상 공개 공유 불가). TV/플립에는 이 링크를 그대로 띄우면 됨.

## 데이터 모델

- `teams`: 9개 팀(플랫폼) — 이름, 컬러, 팀장 이미지(별도 `teamImages` 컬렉션에 저장)
- `days.day1~day4`: 일자별 대진표(토너먼트, 부전승 자동 처리) 또는 순위(완료 시간 기준 자동 정렬 / 수동 순서 지정)
  - Day1: 매치별 "선공/후공 판정" 스톱워치(10초 목표) 포함
  - Day2: 매치별 세트 스코어(예: 2:1) 입력 필드 포함
- `scoring`: Day별 라운드 통과 점수 / 순위별 점수, 임원 참여 가중치(배수), 임원 참여 팀 목록
- `display.activeDayKey`: 송출 화면에 표시할 오늘의 Day (관리자가 "화면 제어" 탭에서 선택)

## 로컬에서 열어보기

`index.html`은 Claude Artifact 런타임(`window.claude`)에 의존하는 `db` 캡슐화 기능을 사용하므로, 로컬에서 그냥 열면 실시간 동기화 없이 "오프라인 모드"(이 브라우저에만 임시 저장)로 동작함. 실제 행사에는 위 게시된 Artifact 링크를 사용할 것.
